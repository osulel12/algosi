# algosi
Решение алгоритмов


Структура:
* [Скользящее окно](13.slid_window) - суть скользящего окна в том, что есть какое-то значение или объект (наше окно) и в место того, чтобы каждый раз делать нашу операцию с начала (к примеру найти кол-во подстрок, где нет повторяющихся символов), мы только преобразовываем предыдущий результаты "границами нового окна". Таким образом сложность алгоритма по времени практически всегда будет линейная O(n), а по памяти константная, так как мы не создаем новых объектов и не выделяем под них память.
* [Куча](14.heap) - "приоритетная очередь". Можем убрать минимум или максимум из последовательности за логарифмическое время. Для узнал с индексом i индекс родителя = как (i - 1) / 2. Для левого ребенка 2*i + 1. Для правого ребенка 2*i +2.
* [Интервалы](15.intervals) - работа с пересечениями интервалов.
* [Связанный список](16.linked_list) - однонаправленный связанный список используют в случае, когда часто нужно добавлять или удалять элементы, а так как эти операции выполняются в нем за константное время O(1), то он будет эффективнее обычного списка.
